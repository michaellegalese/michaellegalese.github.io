L4 documentation

L4 is a programming language for law. You write contracts, legislation and regulations as rules that a computer can check, run and explain.

Get L4

  • VS Code extension: the editor, the l4 command, Legalese AI and deployment in one install.
  • Web editor: try L4 in the browser, nothing to install.

Where to start

  • Learn the language: take the Foundation course. No programming experience needed.
  • Write a rule now: Install L4 and write your first rule takes about 15 minutes.
  • Let AI draft it: Draft rules with Legalese AI turns prose into L4.
  • Put rules to work: Deploy your rules as an API that apps and AI agents can call.
