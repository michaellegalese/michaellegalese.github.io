1e:Tc31,<h1>Tutorials</h1>
<p>Step-by-step guides for getting a task done with L4: from installing it and writing a first rule, to testing and publishing rules, to using them from AI agents and applications. Each guide stands on its own; for the exact meaning of a keyword, follow its links into the <a href="/l4/reference">reference</a>.</p>
<h2 id="start-here">Start here</h2>
<ul>
<li><a href="/l4/tutorials/getting-started/first-l4-file">Install L4 and write your first rule</a>: set up VS Code or the web editor, write a rule and run it.</li>
<li><a href="/l4/tutorials/llm-integration/composing-l4-with-ai">Draft rules with Legalese AI</a>: turn a policy or contract into checked L4 with the AI assistant in VS Code.</li>
</ul>
<h2 id="write-and-check-rules">Write and check rules</h2>
<ul>
<li><a href="/l4/tutorials/getting-started/testing-your-rules">Test your rules</a>: check outcomes with <code>#EVAL</code> and <code>#ASSERT</code>, and simulate obligations with <code>#TRACE</code>.</li>
<li><a href="/l4/tutorials/getting-started/debugging-type-errors">Fix errors</a>: read a diagnostic, and fix the errors that come up most.</li>
<li><a href="/l4/tutorials/getting-started/encoding-legislation">Encode legislation</a>: turn a statutory provision into a tested rule, alone or with an AI assistant.</li>
<li><a href="/l4/tutorials/natural-language-functions/optimising-natural-language-generation">Make rules read like law</a>: infix and mixfix names, and rules that render as readable documents.</li>
<li><a href="/l4/tutorials/getting-started/common-patterns">Common patterns</a>: recipes for records, decisions, calculations, lists, dates and obligations.</li>
</ul>
<h2 id="publish-rules">Publish rules</h2>
<ul>
<li><a href="/l4/tutorials/deploying-rules/exporting-rules-for-deployment">Deploy your rules</a>: mark rules with <code>@export</code>, deploy them to Legalese Cloud and call them.</li>
</ul>
<h2 id="use-deployed-rules">Use deployed rules</h2>
<ul>
<li><a href="/l4/tutorials/legalese-cloud">Choose an integration</a>: compare the ways to use a deployment; addresses, API keys and permissions.</li>
<li><a href="/l4/tutorials/legalese-cloud/ai-agents">Connect an AI agent</a>: Claude, Codex, Cursor, VS Code and other MCP clients, with skills and plugins.</li>
<li><a href="/l4/tutorials/legalese-cloud/openai-compatible-api">Chat with your rules</a>: ask a deployment questions from an OpenAI or Anthropic client.</li>
<li><a href="/l4/tutorials/legalese-cloud/openapi-spec">Call rules over REST</a>: run rules from your own application, and generate a client from OpenAPI.</li>
<li><a href="/l4/tutorials/legalese-cloud/webmcp-embed">Embed rules in a website</a>: one script tag lets visitors' browser agents use your rules.</li>
</ul>
<h2 id="advanced">Advanced</h2>
<ul>
<li><a href="/l4/tutorials/getting-started/l4-cli">Using the l4 CLI</a>: check, run, batch-evaluate, render and deploy rules from the command line.</li>
<li><a href="/l4/tutorials/getting-started/version-control-for-rules">Manage rules in git and CI</a>: commits, review, automatic checks and safe redeployment.</li>
</ul>
