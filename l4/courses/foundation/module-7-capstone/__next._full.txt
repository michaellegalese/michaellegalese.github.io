<h2 id="capstone-project-charity-registration">Capstone Project: Charity Registration</h2>
<p>We'll build a simplified charity registration system based on real legislation. This combines:</p>
<ul>
<li>Type definitions</li>
<li>Eligibility rules</li>
<li>Classification and fee calculations</li>
<li>Regulative obligations and prohibitions</li>
<li>Testing</li>
</ul>
<p>The complete working implementation:</p>
<pre><code class="language-l4-file">-- Module 7: Putting It Together - Capstone Example
-- A complete charity registration system
-- All examples are validated and use natural language identifiers

IMPORT prelude

-- =============================================================================
-- SECTION 1: Type Definitions
-- =============================================================================

-- Charitable purposes (from legislation)
DECLARE Purpose IS ONE OF
    `prevention or relief of poverty`
    `advancement of education`
    `advancement of religion`
    `advancement of health`
    `advancement of animal welfare`
    `other purpose` HAS `the description` IS A STRING

-- Legal status of a charity
DECLARE Status IS ONE OF
    Active
    Suspended HAS `the reason` IS A STRING
    Deregistered

-- Criminal conviction record
DECLARE Conviction
    HAS `the description` IS A STRING
        `the conviction is spent` IS A BOOLEAN

-- Governor of a charity
DECLARE Governor
    HAS `the governor's name` IS A STRING
        `the governor's age` IS A NUMBER
        `the governor is bankrupt` IS A BOOLEAN
        `the governor's convictions` IS A LIST OF Conviction

-- The main charity record
DECLARE `Registered Charity`
    HAS `the charity's name` IS A STRING
        `the registration number` IS A STRING
        `the charity's status` IS A Status
        `the charity's purposes` IS A LIST OF Purpose
        `the charity's governors` IS A LIST OF Governor

-- =============================================================================
-- SECTION 2: Eligibility Rules
-- =============================================================================

-- A governor must be an adult (at least 18)
GIVEN governor IS A Governor
GIVETH A BOOLEAN
DECIDE `the governor is an adult` IF
    governor's `the governor's age` >= 18

-- Check for disqualifying convictions (unspent convictions)
GIVEN governor IS A Governor
GIVETH A BOOLEAN
DECIDE `the governor has a disqualifying conviction` IF
    any (GIVEN c YIELD c's `the conviction is spent` EQUALS FALSE) (governor's `the governor's convictions`)

-- A person can be a governor if they meet all criteria
GIVEN governor IS A Governor
GIVETH A BOOLEAN
DECIDE `the person can be a governor` IF
    `the governor is an adult` governor
    AND NOT governor's `the governor is bankrupt`
    AND NOT `the governor has a disqualifying conviction` governor

-- A purpose is charitable if it's from the approved list
GIVEN purpose IS A Purpose
GIVETH A BOOLEAN
DECIDE `the purpose is charitable` IS
    CONSIDER purpose
    WHEN `prevention or relief of poverty` THEN TRUE
    WHEN `advancement of education` THEN TRUE
    WHEN `advancement of religion` THEN TRUE
    WHEN `advancement of health` THEN TRUE
    WHEN `advancement of animal welfare` THEN TRUE
    WHEN `other purpose` description THEN FALSE

-- A charity is valid if it has valid purposes and valid governors
GIVEN charity IS A `Registered Charity`
GIVETH A BOOLEAN
DECIDE `the charity is valid` IF
    charity's `the charity's status` EQUALS Active
    AND NOT null (charity's `the charity's purposes`)
    AND all (GIVEN p YIELD `the purpose is charitable` p) (charity's `the charity's purposes`)
    AND NOT null (charity's `the charity's governors`)
    AND all (GIVEN g YIELD `the person can be a governor` g) (charity's `the charity's governors`)

-- =============================================================================
-- SECTION 3: Classification and Fees
-- =============================================================================

-- Classify a charity by its annual income (multi-way decision with BRANCH)
GIVEN `the annual income` IS A NUMBER
GIVETH A STRING
DECIDE `the charity's size band` IS
    BRANCH
        IF `the annual income` &#x3C; 10000 THEN "small"
        IF `the annual income` &#x3C; 500000 THEN "medium"
        OTHERWISE "large"

-- The annual filing fee, decomposed with WHERE
GIVEN charity IS A `Registered Charity`
      `the annual income` IS A NUMBER
GIVETH A NUMBER
`the annual filing fee` MEANS
    `the base fee` + `the governor levy`
    WHERE
        `the base fee` MEANS
            BRANCH
                IF `the charity's size band` `the annual income` EQUALS "small" THEN 50
                IF `the charity's size band` `the annual income` EQUALS "medium" THEN 200
                OTHERWISE 500

        `the governor levy` MEANS
            10 * count (charity's `the charity's governors`)

-- =============================================================================
-- SECTION 4: Filing Obligations
-- =============================================================================

-- Actors and actions for the regulatory system
DECLARE Actor IS ONE OF
    `the Charity`
    `the Commissioner`

DECLARE Action IS ONE OF
    `file the annual return`
    `issue a Required Steps Notice`
    `correct the deficiencies`
    `distribute profits to the governors`

-- Annual return filing obligation
GIVEN charity IS A `Registered Charity`
GIVETH A DEONTIC Actor Action
`the annual return obligation` MEANS
    IF charity's `the charity's status` EQUALS Active
    THEN
        PARTY `the Charity`
        MUST `file the annual return`
        WITHIN 60
        HENCE FULFILLED
        LEST
            PARTY `the Commissioner`
            MUST `issue a Required Steps Notice`
            WITHIN 14
            HENCE `the correction period`
            LEST BREACH BY `the Commissioner` BECAUSE "failed to issue notice"
    ELSE FULFILLED

-- After notice is issued, charity has time to correct
GIVETH A DEONTIC Actor Action
`the correction period` MEANS
    PARTY `the Charity`
    MUST `correct the deficiencies`
    WITHIN 30
    HENCE FULFILLED
    LEST BREACH BY `the Charity` BECAUSE "failed to correct after notice"

-- A prohibition: charities must not distribute profits to their governors
GIVETH A DEONTIC Actor Action
`the profit distribution prohibition` MEANS
    PARTY `the Charity`
    SHANT `distribute profits to the governors`
    HENCE FULFILLED
    LEST BREACH BY `the Charity` BECAUSE "distributed profits to governors"

-- =============================================================================
-- SECTION 5: Test Data
-- =============================================================================

-- Valid governor
`Jane Smith` MEANS Governor "Jane Smith" 45 FALSE (LIST)

-- Governor with issues
`John Doe (bankrupt)` MEANS Governor "John Doe" 50 TRUE (LIST)

`unspent conviction` MEANS Conviction "Fraud conviction 2020" FALSE
`Bob Jones (with conviction)` MEANS Governor "Bob Jones" 40 FALSE (LIST `unspent conviction`)

`Young Person` MEANS Governor "Young Person" 16 FALSE (LIST)

-- Valid charity
`Jersey Animal Welfare` MEANS `Registered Charity` "Jersey Animal Welfare" "CH001" Active (LIST `advancement of animal welfare`, `advancement of education`) (LIST `Jane Smith`)

-- Charity with invalid governor
`Problem Charity` MEANS `Registered Charity` "Problem Charity" "CH002" Active (LIST `advancement of education`) (LIST `John Doe (bankrupt)`)

-- Suspended charity
`Suspended Charity` MEANS `Registered Charity` "Suspended Charity" "CH003" (Suspended "Financial irregularities") (LIST `advancement of health`) (LIST `Jane Smith`)

-- =============================================================================
-- SECTION 6: Tests
-- =============================================================================

-- Governor eligibility tests
#EVAL `the governor is an adult` `Jane Smith`
#EVAL `the governor is an adult` `Young Person`
#EVAL `the person can be a governor` `Jane Smith`
#EVAL `the person can be a governor` `John Doe (bankrupt)`
#EVAL `the person can be a governor` `Bob Jones (with conviction)`
#EVAL `the person can be a governor` `Young Person`

-- Charity validity tests

#EVAL `the charity is valid` `Suspended Charity`

-- Classification and fee tests

<h3 id="requirements">Requirements</h3>
<ol>
<li><strong>Charities</strong> have names, registration numbers, statuses, purposes, and governors</li>
<li><strong>Purposes</strong> must be from an approved list</li>
<li><strong>Governors</strong> must be adults without disqualifying convictions</li>
<li><strong>Charities</strong> are classified by income into size bands, which determine the filing fee</li>
<li><strong>Registered charities</strong> must file annual returns within 60 days of year-end</li>
<li><strong>Late filing</strong> triggers a Required Steps Notice</li>
<li><strong>Charities</strong> must not distribute profits to their governors</li>
</ol>

<p>Start by modeling the domain:</p>

DECLARE Purpose IS ONE OF
    `prevention or relief of poverty`
    `advancement of education`
    `advancement of religion`
    `advancement of health`
    `advancement of animal welfare`
    `other purpose` HAS `the description` IS A STRING

-- Legal status of a charity
DECLARE Status IS ONE OF
    Active
    Suspended HAS `the reason` IS A STRING
    Deregistered

-- Criminal conviction record
DECLARE Conviction
    HAS `the description` IS A STRING
        `the conviction is spent` IS A BOOLEAN

-- Governor of a charity
DECLARE Governor
    HAS `the governor's name` IS A STRING
        `the governor's age` IS A NUMBER
        `the governor is bankrupt` IS A BOOLEAN
        `the governor's convictions` IS A LIST OF Conviction

-- The main charity record
DECLARE `Registered Charity`
    HAS `the charity's name` IS A STRING
        `the registration number` IS A STRING
        `the charity's status` IS A Status
        `the charity's purposes` IS A LIST OF Purpose
        `the charity's governors` IS A LIST OF Governor
</code></pre>
<p>Key design decisions:</p>
<ol>
<li><strong>Use natural language field names:</strong> <code>`the governor's name`</code> reads like legal text</li>
<li><strong>Use enumerations for fixed categories:</strong> Prevents typos and invalid values</li>
<li><strong>Use lists for multiple items:</strong> governors, purposes, convictions</li>
</ol>
<hr>
<h2 id="step-2-define-eligibility-rules">Step 2: Define Eligibility Rules</h2>
<p>Rules for who can be a governor and what makes a valid charity:</p>
<pre><code class="language-l4">-- A governor must be an adult (at least 18)
GIVEN governor IS A Governor
GIVETH A BOOLEAN
DECIDE `the governor is an adult` IF
    governor's `the governor's age` >= 18

-- Check for disqualifying convictions (unspent convictions)
GIVEN governor IS A Governor
GIVETH A BOOLEAN
DECIDE `the governor has a disqualifying conviction` IF
    any (GIVEN c YIELD c's `the conviction is spent` EQUALS FALSE) (governor's `the governor's convictions`)

-- A person can be a governor if they meet all criteria
GIVEN governor IS A Governor
GIVETH A BOOLEAN
DECIDE `the person can be a governor` IF
    `the governor is an adult` governor
    AND NOT governor's `the governor is bankrupt`
    AND NOT `the governor has a disqualifying conviction` governor

-- A charity is valid if it has valid purposes and valid governors
GIVEN charity IS A `Registered Charity`
GIVETH A BOOLEAN
DECIDE `the charity is valid` IF
    charity's `the charity's status` EQUALS Active
    AND NOT null (charity's `the charity's purposes`)
    AND all (GIVEN p YIELD `the purpose is charitable` p) (charity's `the charity's purposes`)
    AND NOT null (charity's `the charity's governors`)
    AND all (GIVEN g YIELD `the person can be a governor` g) (charity's `the charity's governors`)
</code></pre>
<p>Key patterns:</p>
<ol>
<li><strong>Simple predicates:</strong> <code>`the governor is an adult`</code></li>
<li><strong>Using <code>any</code> and <code>all</code> with predicates:</strong> checking convictions, purposes, and governors</li>
<li><strong>Combining conditions:</strong> using <code>AND</code> and <code>NOT</code></li>
</ol>
<p><strong>Note:</strong> These functions require <code>IMPORT prelude</code> for <code>any</code>, <code>all</code>, <code>null</code>, etc.</p>
<hr>
<h2 id="step-3-classification-and-fees">Step 3: Classification and Fees</h2>
<p>Constitutive rules from Module 4 in action—a multi-way classification with <code>BRANCH</code>, and a calculation decomposed with <code>WHERE</code>:</p>
<pre><code class="language-l4">-- Classify a charity by its annual income (multi-way decision with BRANCH)
GIVEN `the annual income` IS A NUMBER
GIVETH A STRING
DECIDE `the charity's size band` IS
    BRANCH
        IF `the annual income` &#x3C; 10000 THEN "small"
        IF `the annual income` &#x3C; 500000 THEN "medium"
        OTHERWISE "large"

-- The annual filing fee, decomposed with WHERE
GIVEN charity IS A `Registered Charity`
      `the annual income` IS A NUMBER
GIVETH A NUMBER
`the annual filing fee` MEANS
    `the base fee` + `the governor levy`
    WHERE
        `the base fee` MEANS
            BRANCH
                IF `the charity's size band` `the annual income` EQUALS "small" THEN 50
                IF `the charity's size band` `the annual income` EQUALS "medium" THEN 200
                OTHERWISE 500

        `the governor levy` MEANS
            10 * count (charity's `the charity's governors`)
</code></pre>
<p>Key patterns:</p>
<ol>
<li><strong>BRANCH for classification:</strong> conditions checked top-to-bottom, first match wins</li>
<li><strong>WHERE names each part of the formula:</strong> the fee is transparently <code>base fee + governor levy</code></li>
<li><strong>Reusing decisions:</strong> the fee calculation calls the size-band classification</li>
<li><strong><code>count</code> from the prelude:</strong> the number of items in a list</li>
</ol>
<hr>
<h2 id="step-4-define-regulative-rules">Step 4: Define Regulative Rules</h2>
<p>The filing obligations and a prohibition:</p>
<pre><code class="language-l4">-- Actors and actions for the regulatory system
DECLARE Actor IS ONE OF
    `the Charity`
    `the Commissioner`

DECLARE Action IS ONE OF
    `file the annual return`
    `issue a Required Steps Notice`
    `correct the deficiencies`
    `distribute profits to the governors`

-- Annual return filing obligation
GIVEN charity IS A `Registered Charity`
GIVETH A DEONTIC Actor Action
`the annual return obligation` MEANS
    IF charity's `the charity's status` EQUALS Active
    THEN
        PARTY `the Charity`
        MUST `file the annual return`
        WITHIN 60
        HENCE FULFILLED
        LEST
            PARTY `the Commissioner`
            MUST `issue a Required Steps Notice`
            WITHIN 14
            HENCE `the correction period`
            LEST BREACH BY `the Commissioner` BECAUSE "failed to issue notice"
    ELSE FULFILLED

-- After notice is issued, charity has time to correct
GIVETH A DEONTIC Actor Action
`the correction period` MEANS
    PARTY `the Charity`
    MUST `correct the deficiencies`
    WITHIN 30
    HENCE FULFILLED
    LEST BREACH BY `the Charity` BECAUSE "failed to correct after notice"

-- A prohibition: charities must not distribute profits to their governors
GIVETH A DEONTIC Actor Action
`the profit distribution prohibition` MEANS
    PARTY `the Charity`
    SHANT `distribute profits to the governors`
    HENCE FULFILLED
    LEST BREACH BY `the Charity` BECAUSE "distributed profits to governors"
</code></pre>
<p>Key patterns:</p>
<ol>
<li><strong>Actor and Action types:</strong> Define who can act and what actions exist</li>
<li><strong>Conditional obligations:</strong> Only active charities must file</li>
<li><strong>Chained obligations:</strong> Non-compliance triggers Commissioner action, then a correction period</li>
<li><strong>Prohibitions with SHANT:</strong> what must NOT happen</li>
<li><strong>Clear blame assignment:</strong> <code>BREACH BY ... BECAUSE ...</code></li>
</ol>
<hr>
<h2 id="step-5-create-test-data">Step 5: Create Test Data</h2>
<pre><code class="language-l4">-- Valid governor
`Jane Smith` MEANS Governor "Jane Smith" 45 FALSE (LIST)

-- Governor with issues
`John Doe (bankrupt)` MEANS Governor "John Doe" 50 TRUE (LIST)

`unspent conviction` MEANS Conviction "Fraud conviction 2020" FALSE
`Bob Jones (with conviction)` MEANS Governor "Bob Jones" 40 FALSE (LIST `unspent conviction`)

`Young Person` MEANS Governor "Young Person" 16 FALSE (LIST)

-- Valid charity
`Jersey Animal Welfare` MEANS `Registered Charity` "Jersey Animal Welfare" "CH001" Active (LIST `advancement of animal welfare`, `advancement of education`) (LIST `Jane Smith`)

-- Charity with invalid governor
`Problem Charity` MEANS `Registered Charity` "Problem Charity" "CH002" Active (LIST `advancement of education`) (LIST `John Doe (bankrupt)`)

-- Suspended charity
`Suspended Charity` MEANS `Registered Charity` "Suspended Charity" "CH003" (Suspended "Financial irregularities") (LIST `advancement of health`) (LIST `Jane Smith`)
</code></pre>
<p>Create governors and charities with various characteristics for testing—including ones that should fail.</p>

<h2 id="step-6-test-everything">Step 6: Test Everything</h2>
<h3 id="unit-tests-with-eval">Unit Tests with #EVAL</h3>
<pre><code class="language-l4">#EVAL `the governor is an adult` `Jane Smith`                      -- TRUE
#EVAL `the person can be a governor` `Jane Smith`                  -- TRUE
#EVAL `the person can be a governor` `John Doe (bankrupt)`         -- FALSE
#EVAL `the person can be a governor` `Bob Jones (with conviction)` -- FALSE
#EVAL `the charity is valid` `Jersey Animal Welfare`               -- TRUE
#EVAL `the charity is valid` `Problem Charity`                     -- FALSE

#EVAL `the charity's size band` 60000                              -- "medium"
#EVAL `the annual filing fee` `Jersey Animal Welfare` 60000        -- 210
</code></pre>
<h3 id="scenario-tests-with-trace">Scenario Tests with #TRACE</h3>
<pre><code class="language-l4">-- Happy path: charity files on time
#TRACE `the annual return obligation` `Jersey Animal Welfare` AT 0 WITH
    PARTY `the Charity` DOES `file the annual return` AT 30
-- Result: FULFILLED

-- Suspended charity: no filing required
#TRACE `the annual return obligation` `Suspended Charity` AT 0 WITH
-- Result: FULFILLED

-- Late filing: the charity misses the 60-day deadline (its day-65 filing
-- arrives too late), the Commissioner issues a notice, then the charity
-- corrects within the correction period
#TRACE `the annual return obligation` `Jersey Animal Welfare` AT 0 WITH
    PARTY `the Charity` DOES `file the annual return` AT 65
    PARTY `the Commissioner` DOES `issue a Required Steps Notice` AT 70
    PARTY `the Charity` DOES `correct the deficiencies` AT 90
-- Result: FULFILLED

-- Prohibition: distributing profits is a breach
#TRACE `the profit distribution prohibition` AT 0 WITH
    PARTY `the Charity` DOES `distribute profits to the governors` AT 10
-- Result: BREACH BY `the Charity` BECAUSE "distributed profits to governors"
</code></pre>

<h2 id="organizing-code-with-sections">Organizing Code with Sections</h2>
<p>Use sections (<code>§</code>) to organize larger files:</p>
<pre><code class="language-l4">§ `Charity Registration System`

§§ `Type Definitions`

§§ `Eligibility Rules`

§§ `Filing Obligations`

§§ `Tests`

<ul>
<li><code>§</code> - Top-level section</li>
<li><code>§§</code> - Sub-section</li>
<li><code>§§§</code> - Sub-sub-section</li>
</ul>

<h2 id="best-practices">Best Practices</h2>
<h3 id="1-start-with-types">1. Start with Types</h3>
<pre><code class="language-l4">-- Good: Clear domain model
DECLARE Application
    HAS `the applicant` IS A `Legal Entity`
        `the purposes` IS A LIST OF Purpose
        `the documents` IS A LIST OF Document
</code></pre>
<h3 id="2-small-focused-functions">2. Small, Focused Functions</h3>
<pre><code class="language-l4">-- Good: Single responsibility
DECIDE `the governor is an adult` IF governor's `the governor's age` >= 18
DECIDE `the governor is not bankrupt` IF NOT governor's `the governor is bankrupt`

-- Combine them
DECIDE `the person can be a governor` IF
    `the governor is an adult` governor
    AND `the governor is not bankrupt` governor
</code></pre>
<h3 id="3-test-every-path">3. Test Every Path</h3>
<pre><code class="language-l4">-- Happy path
#EVAL `the person can be a governor` `Jane Smith`             -- TRUE

-- Error cases
#EVAL `the person can be a governor` `John Doe (bankrupt)`    -- FALSE
#EVAL `the person can be a governor` `Young Person`           -- FALSE
</code></pre>
<h3 id="4-use-descriptive-names">4. Use Descriptive Names</h3>
<pre><code class="language-l4">-- Good: Clear, readable names
DECIDE `the charity meets filing requirements` IF ...

-- Bad: Cryptic names
DECIDE check1 IF ...
</code></pre>
<h3 id="5-document-complex-logic">5. Document Complex Logic</h3>
<pre><code class="language-l4">-- The charity test requires:
-- 1. All purposes must be from the statutory list (Art 5)
-- 2. The charity must provide public benefit (Art 7)
-- 3. All governors must be fit and proper (Art 19)
DECIDE `meets charity test` IF ...
</code></pre>

<h2 id="debugging">Debugging</h2>
<p>When something doesn't work, read the first error, fix it, and check again: one error often causes several more. Common causes are a misspelled name or a type with no <code>DECLARE</code>, a field access passed to a function without parentheses (<code>count (x's field)</code>, not <code>count x's field</code>), an <code>IF</code> condition that is not a <code>BOOLEAN</code>, a call with too few arguments for its <code>GIVEN</code>, and fields not aligned under <code>HAS</code>. <a href="/l4/tutorials/getting-started/debugging-type-errors">Fix errors</a> goes through each kind of error message and how to fix it.</p>
