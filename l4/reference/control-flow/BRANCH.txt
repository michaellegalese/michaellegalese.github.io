1f:Tcb7,<h1>BRANCH</h1>
<p><code>BRANCH</code> chooses between several values by a list of conditions. The conditions are tried from top to bottom, and the first one that holds gives the result. <code>OTHERWISE</code> gives the result when none holds.</p>
<h2 id="syntax">Syntax</h2>
<pre><code class="language-text">BRANCH IF condition1 THEN value1
       IF condition2 THEN value2
       OTHERWISE default-value

BRANCH
  IF condition1 THEN value1
  IF condition2 THEN value2
  OTHERWISE default-value
</code></pre>
<ul>
<li>Each <code>IF … THEN</code> and the <code>OTHERWISE</code> must be indented further than the <code>BRANCH</code> keyword. Put them in one column, either after <code>BRANCH</code> on its line or on the lines below.</li>
<li><code>OTHERWISE</code> is required.</li>
<li>Every value must have the same type.</li>
</ul>
<p><strong>Example file:</strong></p>
<pre><code class="language-l4-file">-- BRANCH examples

-- The conditions are tried from top to bottom; the first that holds gives the result.

DECLARE Category IS ONE OF Standard, Premium, Enterprise

GIVEN category IS A Category
GIVETH A NUMBER
`monthly price for` category MEANS
  BRANCH IF category EQUALS Standard   THEN 10
         IF category EQUALS Premium    THEN 25
         IF category EQUALS Enterprise THEN 100
         OTHERWISE 0

#EVAL `monthly price for` Premium

-- The IF lines can also start on the line below BRANCH,
-- indented further than BRANCH itself.

GIVEN `annual income` IS A NUMBER
GIVETH A NUMBER
`tax rate for` `annual income` MEANS
  BRANCH
    IF `annual income` > 120000 THEN 0.4
    IF `annual income` > 50000  THEN 0.3
    IF `annual income` > 20000  THEN 0.2
    OTHERWISE 0

-- 150000 is above 50000 too, but the first condition that holds wins.
#EVAL `tax rate for` 150000
#EVAL `tax rate for` 60000
#EVAL `tax rate for` 10000
</code></pre>
<h2 id="example">Example</h2>
<pre><code class="language-l4">GIVEN `annual income` IS A NUMBER
GIVETH A NUMBER
`tax rate for` `annual income` MEANS
  BRANCH
    IF `annual income` > 120000 THEN 0.4
    IF `annual income` > 50000  THEN 0.3
    IF `annual income` > 20000  THEN 0.2
    OTHERWISE 0
</code></pre>
<p><code>`tax rate for` 150000</code> gives <code>0.4</code>: 150000 is above 50000 as well, but the first condition that holds wins.</p>
<h2 id="branch-if-or-consider">BRANCH, IF or CONSIDER</h2>
<table>
<thead>
<tr>
<th>Situation</th>
<th>Use</th>
</tr>
</thead>
<tbody>
<tr>
<td>one condition, two outcomes</td>
<td><a href="/l4/reference/control-flow/IF">IF</a></td>
</tr>
<tr>
<td>several conditions, tried in order</td>
<td><code>BRANCH</code></td>
</tr>
<tr>
<td>the value's shape: enumeration values, <code>JUST</code>/<code>NOTHING</code>, list or record fields</td>
<td><a href="/l4/reference/control-flow/CONSIDER">CONSIDER</a></td>
</tr>
</tbody>
</table>
<p><code>BRANCH</code> gives the same result as <code>IF … ELSE IF … ELSE</code>, without nesting each <code>IF</code> deeper.</p>
