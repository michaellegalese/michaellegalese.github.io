3:T4e2,<h1>Control flow</h1>
<p>L4 has no statements, only expressions, so choosing between results is done with expressions that give a value.
<code>IF</code> and <code>BRANCH</code> choose by conditions; <code>CONSIDER</code> chooses by the shape of a value. In each, every outcome must have the same type.</p>
<h2 id="pages">Pages</h2>
<ul>
<li><a href="/l4/reference/control-flow/IF">IF</a>: <code>IF … THEN … ELSE</code>, one condition and two outcomes</li>
<li><a href="/l4/reference/control-flow/BRANCH">BRANCH</a>: several conditions, tried from top to bottom, with <code>OTHERWISE</code></li>
<li><a href="/l4/reference/control-flow/CONSIDER">CONSIDER</a>: pattern matching with <code>WHEN … THEN</code> and <code>OTHERWISE</code>, and the check for missing branches</li>
</ul>
<p>A function can also be written as <a href="/l4/reference/functions/DECIDE#several-clauses">several clauses</a>, one per case, which means the same as a <code>CONSIDER</code>.
Conditions are combined with <a href="/l4/reference/operators/logical">AND, OR, NOT, IMPLIES</a> and <a href="/l4/reference/operators/UNLESS">UNLESS</a>.</p>
<p>The <a href="/l4/courses/foundation/module-3-control-flow">Foundation course, module 3</a> teaches these step by step.</p>
