3:T1e76,<h1>excel-date</h1>
<p>Excel-compatible date helpers: serial conversion (including Excel's 1900 leap-year bug), date differences (<code>DATEDIF</code>, <code>DAYS360</code>, <code>YEARFRAC</code>), month arithmetic (<code>EDATE</code>/<code>EOMONTH</code> equivalents), and workday calculations. Import it with <code>IMPORT `excel-date`</code> (the backticks are needed because of the hyphen). Import <code>daydate</code> too if you build dates with <code>Date</code>.</p>

<h2 id="days-and-datedif">DAYS and DATEDIF</h2>
<table>

<td><code>ExcelDays</code> endDate startDate</td>
<td><code>DATE → DATE → NUMBER</code></td>
<td>Days between (end − start); also has a <code>NUMBER → NUMBER → NUMBER</code> overload for serials</td>
</tr>
<tr>
<td><code>DATEDIF</code> startDate endDate unit</td>
<td><code>DATE → DATE → STRING → EITHER STRING NUMBER</code></td>
<td>Excel <code>DATEDIF</code> with units <code>"Y"</code>, <code>"M"</code>, <code>"D"</code>, <code>"MD"</code>, <code>"YM"</code>, <code>"YD"</code>; LEFT if start > end or unit unknown</td>
</tr>
