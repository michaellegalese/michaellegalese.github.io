3:T9ea,<h1>timezone</h1>
<p>Constants that give the IANA name of common time zones, for <code>TIMEZONE IS</code> lines and the <a href="/l4/reference/libraries/datetime">datetime</a> constructors. Import it with <code>IMPORT timezone</code>.</p>
<p><strong>Example:</strong></p>
<pre><code class="language-l4-file">-- Timezone Example: IANA timezone constants
IMPORT timezone

-- Set document timezone using a constant
TIMEZONE IS EST

-- Verify the resolved IANA name
DECIDE `document timezone` IS TIMEZONE
#EVAL `document timezone`  -- "America/New_York"

-- Timezone constants resolve to IANA strings
#EVAL EST  -- "America/New_York"
#EVAL PST  -- "America/Los_Angeles"
#EVAL SGT  -- "Asia/Singapore"
#EVAL UTC  -- "Etc/UTC"

-- EST and EDT map to the same zone (DST handled automatically)
#ASSERT EST EQUALS EDT
</code></pre>
<h2 id="setting-the-document-time-zone">Setting the document time zone</h2>
<pre><code class="language-l4">IMPORT timezone

TIMEZONE IS SGT
</code></pre>
<p>sets the document's time zone to <code>"Asia/Singapore"</code>. Without the library, write the IANA name itself:</p>
<pre><code class="language-l4">TIMEZONE IS "Asia/Singapore"
</code></pre>

<h2 id="daylight-saving-time">Daylight saving time</h2>
<p>The standard and the daylight-saving abbreviation of a zone give the same IANA name, so <code>EST</code> and <code>EDT</code> are both <code>"America/New_York"</code>. Whether daylight saving applies is worked out from the date, not from the abbreviation you chose.</p>

#ASSERT EST EQUALS EDT
