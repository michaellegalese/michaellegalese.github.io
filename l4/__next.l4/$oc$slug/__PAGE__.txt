<h1>L4 documentation</h1>
<p>L4 is a programming language for law. You write contracts, legislation and regulations as rules that a computer can check, run and explain.</p>
<h2 id="get-l4">Get L4</h2>
<ul>
<li><strong><a href="https://marketplace.visualstudio.com/items?itemName=Legalese.l4-vscode">VS Code extension</a></strong>: the editor, the <code>l4</code> command, Legalese AI and deployment in one install.</li>
<li><strong><a href="https://jl4.legalese.com">Web editor</a></strong>: try L4 in the browser, nothing to install.</li>
</ul>
<h2 id="where-to-start">Where to start</h2>
<ul>
<li><strong>Learn the language:</strong> take the <a href="/l4/courses/foundation">Foundation course</a>. No programming experience needed.</li>
<li><strong>Write a rule now:</strong> <a href="/l4/tutorials/getting-started/first-l4-file">Install L4 and write your first rule</a> takes about 15 minutes.</li>
<li><strong>Let AI draft it:</strong> <a href="/l4/tutorials/llm-integration/composing-l4-with-ai">Draft rules with Legalese AI</a> turns prose into L4.</li>
<li><strong>Put rules to work:</strong> <a href="/l4/tutorials/deploying-rules/exporting-rules-for-deployment">Deploy your rules</a> as an API that apps and AI agents can call.</li>
</ul>
